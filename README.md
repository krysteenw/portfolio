# Chada Tech Clocks

## Project Overview

This project, titled "Chada Tech Clocks," was developed as part of the CS 210 course. The program displays the current time in both 12-hour and 24-hour formats simultaneously. It is designed to be a user-friendly interface for viewing the time in both formats, which can be particularly useful in international contexts where different regions use different time conventions.

## Features

- Simultaneously displays the time in 12-hour and 24-hour formats.
- The clock updates every second to ensure accurate timekeeping.
- The program is written in C++ and follows object-oriented programming principles.
- Clean, modular code with comprehensive documentation.

## Files Included

- `main.cpp`: The main program file that contains the implementation of the dual clock display.
- `Clock.h`: Header file for the Clock class, which manages the time display.
- `Clock.cpp`: Implementation file for the Clock class.
- `README.md`: This file, containing an overview of the project and reflections on the development process.

## How to Run

1. Clone this repository to your local machine.
2. Open the project in your preferred C++ development environment.
3. Compile and run the program.

## Reflection

The Chada Tech Clocks project addresses the need for users to view the current time in both 12-hour and 24-hour formats simultaneously. This is particularly useful in global environments where different time formats are used. The program provides a simple and intuitive interface for this purpose.
